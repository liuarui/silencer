# Silencer 1.1.0

新增三端捕获模式：Windows 10/11 x64、macOS 14+（Intel / Apple Silicon）、Ubuntu 24.04 x64（内核 6.8+）。无需修改 AI 客户端 API 地址或 Key，网页提供安装、授权、证书信任、链路检查，以及修复、更新和卸载引导。

## 使用

- 在现有控制台选择「捕获模式」，按浏览器系统提示执行安装脚本，随后进入本机同一套网页向导。
- 默认本地处理；也可选择经过验证的 HTTPS Silencer 服务器。规则、日志、映射属于各自处理端，不自动迁移或失败回退。
- 四个 `silencer-local-*` 文件为原生安装资源；`manifest.json` 与 `SHA256SUMS` 为安装器校验文件。
- 独立脚本默认从本仓库最新 Release 下载资源，也可通过 `SILENCER_RELEASE_BASE` 指定经过审核的 HTTPS 镜像。
- Docker 标签 `liuarui/silencer:1.1.0`、`1.1`、`latest` 均提供 linux/amd64 和 linux/arm64。Docker 用于服务器部署，不在容器内捕获宿主机网络。

## 验证与兼容边界

原生包流水线覆盖四种系统/架构的构建、运行依赖、真实 C++ 脱敏还原与供应商凭据隔离；镜像逐架构验证后再发布。安装器覆盖重复安装、修复、中断恢复、完整性校验与卸载保留数据。Windows 另补齐日志句柄删除、SQLite 盘符备份路径、私有配置及备份 ACL 与原生全量 Go 测试。

macOS 已进行 cc-switch / Claude Code 与 Clash Verge TUN 联调。Windows/Linux 系统权限、UAC/eBPF、第三方代理共存仍需各自实机验证，CI 包验证不能证明应用已受到捕获保护。macOS 不捕获回环流量；本机网关需将真实模型域名加入保护目标并信任本机 CA。

系统授权和证书信任需要用户完成。支持 HTTP/HTTPS AI API、JSON/SSE/NDJSON 与工具参数；不包含 AI 网页聊天协议、WebSocket 内容脱敏、音视频、WSL 或容器内捕获。未识别目标不解密，处理失败阻断，后台退出后不提供永久断网开关。保护范围须用请求账本核验。

每台安装独立生成 CA；升级保留身份，卸载默认保留业务数据并提供清理引导。Silencer 自身 macOS 二进制为 ad-hoc 签名，未做 Developer ID 公证；官方 mitmproxy 应用签名保持原样。Windows 包未做 Authenticode 签名，系统可能提示来源确认。

浏览器扩展继续保持私有，不随此版本发布。反向代理、命名路由和历史数据保持兼容。详见 [捕获说明](../CAPTURE.md) 与 [发布流程](../PUBLISHING.md)。
