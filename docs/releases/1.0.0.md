# Silencer 1.0.0 — 2026-10-16

The first stable release includes the Go gateway, C++ masking engine and React console.

- Durable scoped mappings preserve placeholder identities across turns, retained history, restarts and log clearing.
- JSON, SSE and NDJSON restore ordinary replies and tool-call parameters.
- Tool-call protection supports observe, confirmation rewrite and block; observe is the default.
- Logs include anomaly filters, exact 404 noise allowlists and masked original-data views.
- Fixes cover canceled terminal-frame cleanup, extra-header forwarding, shared upstream connections and probe HTTP status classification.
- Bounded heap-backed regex matching handles long inputs without the former recursive native stack path. Compatibility tests cover empty classes, NUL escapes, backreferences and email match spans.
- Default containers persist runtime settings and administrator password changes across recreation; MySQL templates honor custom database usernames.
- Browser plugin source, dedicated pages, installation guides and downloads are excluded.

Validation for the gateway release included strict C++, Go native race tests, frontend build and log/privacy tests, and 118 isolated protocol/lifecycle/tool-policy checks across SQLite and MySQL. The public snapshot has an independent core verification gate and Docker configuration-persistence smoke test. MySQL tests require a disposable database; libFuzzer smoke requires an available sanitizer runtime.

Images: [`liuarui/silencer:1.0.0`](https://hub.docker.com/r/liuarui/silencer) and `latest`, currently `linux/amd64`. Build other supported targets from source as needed.
