# Silencer 1.1.1

修复工具参数中的普通长标识符被误判为未还原占位符，导致网关截断流式响应、Hermes 提示 `Stream stalled mid tool-call` 的问题。

- 占位符检查遵守完整标识符边界，不再匹配普通长字符串内部的片段。
- 跨事件检查保留上下文，并等待后续字符确认右边界；响应完成或 EOF 时检查剩余候选。
- 真正无法还原的工具参数仍然阻断；JSON 转义、Unicode 转义、快照及自定义工具输入继续接受检查。
- 回归测试覆盖 OpenAI、Anthropic、Responses 与自定义工具输入的事件切分，以及正常占位符还原和未知占位符拒绝。

Docker 标签 `liuarui/silencer:1.1.1`、`1.1`、`latest` 提供 linux/amd64 和 linux/arm64。原生安装包继续覆盖 Windows x64、Linux x64、macOS Intel / Apple Silicon。升级沿用已有配置、映射和数据库，无需迁移。

本次修复针对工具流误中断，不代表消除所有模型重复输出或上游连接错误。Windows/Linux 系统权限、UAC/eBPF 和第三方代理共存仍需实机验证；CI 包测试不等同于系统捕获保护验证。其余兼容边界见 [1.1.0 发布说明](1.1.0.md)。
