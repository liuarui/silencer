HOW IT WORKS

客户端不需要改变习惯

把 Base URL 指向 Silencer，网关负责接收、保护、转发和还原。配置集中在控制台，数据目录可持久化到本地卷或数据库。

  4. 04还原回复回到客户端时恢复上下文
