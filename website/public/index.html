HOW IT WORKS

客户端不需要改变习惯

捕获模式在本机接管已启用的 AI API 目标，客户端保留原地址与 Key。反向代理模式通过 Silencer Base URL 接入。两种入口共用脱敏、转发、流式还原和工具防护。

了解核心能力 →
  1. 01接入选择本机捕获或反向代理入口
  2. 02保护敏感内容转换为稳定占位符
  3. 03转发请求送往选定的模型上游
  4. 04还原回复回到客户端时恢复上下文
